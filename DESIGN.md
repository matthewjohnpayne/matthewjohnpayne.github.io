# ScientistWebsite visual direction · Approved for v0.1

## Character

Inspired by the clarity of **Seeing Theory**, **R2D3**, and the user's own MPC orbit notebooks, without reproducing their layouts or scientific artwork.

The science creates the visual interest. The interface provides structure, readability and breathing room.

## The homepage

- Calm **dark hero** (`#0b1926`) for personal introduction, portrait and integrated orbital experiment.
- **Light lower section** (`#f8faf9`) for research, tutorials, software, MPC and links to publications/people.
- Introductory typography is modern sans-serif, moderate in scale and never ornamental.
- Scientific figures and orbit trajectories use teal/aqua, a warm orange accent, and muted neutral tones.
- Avoid thick decorative frames, star-field wallpaper, glossy gradients, photomontages, decorative asteroids and an all-over JPL/PHA aesthetic.
- Leave ample whitespace but do not make the layout artificially sparse.
- The portrait should be a real user-approved photo, not a synthetic person.

## Colors

| Usage | Hex |
| --- | --- |
| Header / hero | `#0b1926` |
| Light surfaces | `#f8faf9` |
| Text | `#1b3040` |
| Muted body text | `#435866` |
| Interactive link | `#078d97` |
| Orbit teal | `#4fced2` |
| Warm orbit marker | `#e9a160` |

Colors in scientific figures encode bodies, variables or states. They should not be added purely for decoration. Later scientifically specialized color schemes may differ when clarity requires it.

## Interactive design

Controls should be recognizable plain controls with concise labels. Simulations must be fully usable by mouse, keyboard or touch, have play/pause and reset, and not autoplay when the page opens. Respect reduced-motion preferences. For real MPC data orbits, cite dataset and integration method separately from the design.

## Responsive principles

At desktop widths the hero is a two-column composition (professional introduction + orbital laboratory). At tablet/mobile widths the columns stack, navigation becomes a menu, and cards become single-column. Do not hide scientifically substantive content purely because the viewport is narrow.
